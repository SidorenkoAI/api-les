## Лёгкие

### 1. Найди шесть ошибок

В файле `broken.json` описана новая комета, но в нём **шесть ошибок** формата JSON. Найди и
исправь их все, сохрани исправленную версию как `comet_fixed.json`. Потом напиши программу,
которая загружает `comet_fixed.json` и печатает имя кометы и её луны.

- Сначала попробуй загрузить `broken.json` через `json.load` и прочитай сообщение об ошибке:
  в нём есть номер строки (`line`) и столбца (`column`).
- Python показывает только **первую** ошибку. Исправил — запусти снова.
- Вспомни правила: какие кавычки? как пишется «истина»? можно ли запятую в конце? а комментарии?
- PyCharm подчёркивает ошибки в JSON красным — сверься с ним.

### 2. Опыты с `dumps` и `loads`

Напиши программу-«лабораторию» и ответь на вопросы, глядя на то, что она печатает:

1. Чем отличается `json.dumps(planet)` от `json.dumps(planet, ensure_ascii=False)`?
2. Что делает `indent=2`? А `indent=4`?
3. Во что превращаются `True`, `False`, `None`, кортеж `(1, 2)`?
4. Словарь `{1: "один", 2: "два"}` перевели в JSON и обратно. Какие у него теперь ключи? Работает
   ли `data[1]`?
5. Что будет, если попробовать `json.dumps({1, 2, 3})` (множество)? Поймай ошибку через
   `try`/`except` и напечатай её.

- Для пятого вопроса: ошибка называется `TypeError`.
- Чтобы сравнить «до» и «после», печатай `type(...)` и сравнивай через `==`.

### 3. Своя планета

Программа спрашивает имя новой планеты, её тип, гравитацию и луны (через запятую), добавляет
планету в список и сохраняет **всё** в `my_planets.json`. Исходный `planets.json` не трогаем.

- `id` новой планеты — на 1 больше самого большого `id` в списке.
- Гравитация из `input` — строка, а нужна дробь: `float(...)`.
- Луны: `"Тик, Так".split(",")` даёт `['Тик', ' Так']` — лишние пробелы убери через `.strip()`.
  А если ввели пустую строку — лун нет, нужен пустой список.
- Остальные поля (температура, атмосфера…) можно заполнить значениями по умолчанию.
- Открой `my_planets.json` в PyCharm: твоя планета в самом конце?

## Средние

### 4. Избранное между запусками

Программа ведёт список избранных планет. При запуске показывает, что уже в избранном, затем
спрашивает планеты, которые добавить (пустая строка — конец). После каждого добавления сохраняет
избранное в `favorites.json`. Запусти программу два раза: избранное должно **сохраниться**.

- Самое интересное — первый запуск: файла `favorites.json` ещё нет. `json.load` упадёт с
  `FileNotFoundError`. Поймай её и начни с пустого списка.
- Не добавляй планету, которой нет в `planets.json`, и не добавляй одну планету дважды.
- Что хранить в избранном — имена или `id`? Подумай, что будет, если планету переименуют.

### 5. Отчёт по типам

Создай файл `report_by_type.json`, в котором для каждого типа планет записано: сколько планет,
их имена и общее население:

```json
{
  "ocean": {
    "count": 2,
    "names": ["Аквамарина", "Мурлыка"],
    "population": 1036000
  },
  ...
}
```

- Это словарь словарей. Похоже на задание 5 урока 1, только внутри не список, а словарь.
- Когда тип встречается впервые, создай для него `{"count": 0, "names": [], "population": 0}`.

### 6. Безопасная загрузка

Напиши функцию `load_json(path)`, которая загружает JSON из файла. Если что-то не так, она
**не падает**, а печатает понятное сообщение и возвращает `None`:

```
Файл nofile.json не найден.
Файл broken.json испорчен: строка 2, столбец 3 — Expecting property name enclosed in double quotes
```

Проверь её на трёх файлах: `planets.json`, `broken.json` и несуществующем `nofile.json`.

- `try` / `except FileNotFoundError` / `except json.JSONDecodeError as error`.
- У ошибки `JSONDecodeError` есть поля `error.lineno` (строка), `error.colno` (столбец),
  `error.msg` (что не так).
- Эта функция пригодится в следующих заданиях, а потом и в работе с сервером.

## Посложнее

### 7. Редактор справочника

Программа с меню:

```
1 — показать все планеты
2 — добавить планету
3 — удалить планету
4 — сохранить
0 — выход
```

Работает с файлом `planets_edit.json`. Если его нет — начинает с копии `planets.json`.
При выходе без сохранения спрашивает: «Сохранить изменения? (да/нет)».

- Меню — цикл `while True` и `if`/`elif` по введённой цифре.
- Удаление из списка по имени: найди планету, потом `planets.remove(planet)`.
- Как узнать, что есть несохранённые изменения? Заведи переменную-флаг `changed`.
- Функции `load_json` (задание 6) и «сохранить» сделают код короче.

### 8. Что изменилось?

В файле `planets_new.json` — новая версия справочника. Там что-то добавили, что-то удалили и
что-то поменяли. Напиши программу, которая сравнивает `planets.json` и `planets_new.json` и
печатает отчёт:

```
Добавлены: Комета-Х
Удалены: Фригория
Изменены:
  Аквамарина: moons [] → ['Жемчужина']
  ...
```

- Планеты удобно сравнивать по `id`. Сделай из каждого списка словарь `{id: планета}`.
- Добавлены — `id` есть в новом, но нет в старом. Удалены — наоборот.
- Для планет, которые есть в обоих: пройди по ключам словаря и сравни значения.
- Проверь программу на своём `my_planets.json` из задания 3.
