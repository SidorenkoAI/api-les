# Урок 8. Свой API на FastAPI

## Цель

Посмотреть на всю историю курса **со стороны сервера**. Семь уроков ученики были клиентами:
отправляли запросы Космопорту и разбирали его JSON. Сегодня они пишут сервер сами — маленький
API **«Космический зоопарк»** на FastAPI — и дают его адрес соседу по парте, а сосед ходит к нему
тем же `requests`, что на уроках 3–7.

Что разбираем: маршрут (`@app.get`), параметры пути (`/animals/3`) и запроса
(`/animals?planet=Мурлыка`), возврат словаря → JSON, ошибка 404 (`HTTPException`), приём тела
POST через модель Pydantic (и бесплатная проверка данных — 422), страница `/docs`, которая
появляется сама. Итог — работающий сервер у каждого и клиент `client.py`, которым ученики
ходят друг к другу по локальной сети.

## Перед началом

- **Поставьте `fastapi` и `uvicorn` заранее** на всех компьютерах — на уроке на это уйдёт
  время, а школьный интернет может быть медленным. В PyCharm: внизу вкладка **Terminal** →
  `pip install fastapi uvicorn` (или **Settings → Project → Python Interpreter → «+»**, найти
  `fastapi`, **Install Package**, затем так же `uvicorn`). Проверка: в Python Console
  `import fastapi, uvicorn` — без ошибок. Нужен Python 3.10 или новее (из-за записи `str | None`).
- **Проверьте сеть заранее, на двух компьютерах класса.** На одном запустите `main.py`, на
  другом откройте в браузере `http://<IP первого>:8000/docs`. Если открылось — урок пройдёт
  по плану. Если нет — см. «Частые проблемы» ниже; в худшем случае ученики работают каждый у
  себя (`127.0.0.1`), а «соседский» сервер запускаете вы на своём компьютере.
- Узнайте, как найти **IP компьютера**: `ipconfig` в терминале → строка «IPv4-адрес»
  (`192.168.…` или `10.…`). Можно заранее выписать IP всех компьютеров на листок.
- Раздайте `main.py` **пустым** — будем писать с нуля, — а `client.py` — готовым: клиент
  ученики уже умеют писать, это повторение, и время лучше потратить на сервер.
- Разбейте класс на **пары** (при 5 учениках — пара, пара и тройка по кругу): каждый —
  и хозяин своего зоопарка, и посетитель соседского.

## Теория (10 минут)

- **Теперь вы по ту сторону.** Нарисуйте на доске схему урока 3: клиент → запрос → сервер →
  ответ → клиент. Семь уроков мы были в левой части. Всё, что мы видели у Космопорта, кто-то
  **написал**: адрес `/planets/{id}`, параметры `?type=gas`, ответ 404 «нет такой планеты»,
  POST с телом, страницу `/docs`. Сегодня пишем это сами — и это неожиданно мало кода.
- **Сервер — это программа, которая ждёт.** Обычный скрипт выполнился и закончился. Сервер
  запускается и **не заканчивается**: сидит и ждёт запросов, на каждый вызывает нужную
  функцию. Поэтому в PyCharm он «висит», пока не нажать Stop, — это нормально.
- **Маршрут** — пара «метод + путь» → функция. `@app.get("/animals")` значит: «когда придёт
  GET на `/animals`, вызови функцию ниже». Строка с `@` — **декоратор**, она «приклеивает»
  функцию к адресу. Подробно разбирать декораторы не нужно, достаточно этой фразы.
- **Что вернула функция — то и ответ.** Вернули словарь — FastAPI сам сделает из него JSON
  (`json.dumps` из урока 2 происходит без нас) и код 200.
- **Параметры.** В адресе `/animals/{animal_id}` кусок в фигурных скобках попадёт в аргумент
  функции `animal_id`. Аргумент, которого нет в адресе, — параметр запроса: `?planet=...`.
  Аннотация `animal_id: int` — не украшение: FastAPI по ней **сам проверит** и переведёт
  строку из адреса в число, а на `/animals/abc` ответит **422**.
- **Связь с уроками 3–7** — табличка на доске:

  | Клиент (уроки 3–7) | Сервер (сегодня) |
  |---|---|
  | `requests.get(BASE_URL + "/animals/3")` | `@app.get("/animals/{animal_id}")` |
  | `params={"planet": "Мурлыка"}` | аргумент `planet: str \| None = None` |
  | `response.json()` | `return {...}` |
  | `if response.status_code == 404` | `raise HTTPException(status_code=404, ...)` |
  | `requests.post(..., json={...})` | `@app.post(...)` + модель `NewAnimal` |
  | открыть `/docs` | ничего не делать — `/docs` есть сам |

## Пошаговый план занятия

1. **Первый маршрут — 5 строк.** Пустой `main.py`:

   ```python
   import uvicorn
   from fastapi import FastAPI

   app = FastAPI(title="Космический зоопарк")

   @app.get("/")
   def welcome():
       return {"message": "Добро пожаловать в Космический зоопарк!"}

   if __name__ == "__main__":
       uvicorn.run(app, host="127.0.0.1", port=8000)
   ```

   Кнопка **Run**. В консоли — `Uvicorn running on http://127.0.0.1:8000`, программа «висит».
   Откройте в браузере http://127.0.0.1:8000 — там ваш JSON. Вы написали API!
   Пусть ученики поменяют текст, перезапустят (Stop → Run, или Rerun) и обновят страницу.
   **Важно:** после каждой правки сервер нужно перезапускать, иначе работает старый код.

2. **`/docs` бесплатно.** Откройте http://127.0.0.1:8000/docs. Это та же страница, что у
   Космопорта, — FastAPI построил её сам по нашим функциям. Тот же Swagger, тот же **Try it out**.
   Вот откуда она была у Космопорта: его сервер тоже написан на FastAPI (покажите `server/main.py`,
   если есть время, — это просто больше таких же функций).

3. **Данные зоопарка и список.** Вставьте список `animals` (раздайте готовым, чтобы не
   набирать) и маршрут `@app.get("/animals")`, который возвращает `{"count": ..., "animals": ...}`.
   Почему словарь, а не просто список? Так удобно добавлять поля потом, не ломая клиентов.

4. **Параметр пути и 404.** `@app.get("/animals/{animal_id}")`, перебор циклом, `return animal`.
   Если цикл закончился, а зверя нет — `raise HTTPException(status_code=404, detail="...")`.
   Попробуйте в браузере `/animals/3`, `/animals/99` (404 и наш текст) и `/animals/abc` (422 —
   это FastAPI проверил `int` сам, мы ничего не писали). Вспомните урок 4: у Космопорта на
   неверные параметры было 400 — там автор сервера специально переделал 422 в 400 с русским
   текстом. По умолчанию FastAPI отвечает 422 и пишет по-английски.

5. **Параметр запроса.** Добавьте `planet: str | None = None` в функцию списка и `if` в цикл.
   `/animals?planet=Мурлыка`. `None` по умолчанию — значит, параметр необязательный. В `/docs`
   у параметра появилось поле ввода.

6. **POST и модель.** Класс `NewAnimal(BaseModel)` — «какие поля и каких типов должны быть в
   теле». Маршрут `@app.post("/animals", status_code=201)` с аргументом `new: NewAnimal`.
   Попробуйте в `/docs`: нормальный зверь → **201**; `"age": "старый"` → **422** с объяснением;
   без поля `planet` → **422** «Field required». Проверку тела мы не писали — её сделал Pydantic
   по описанию модели. Перезапустите сервер — новый зверь пропал: данные живут в памяти
   (как сохранять — задание 8).

7. **Открываем соседу (5 минут).** Замените в `uvicorn.run` `host="127.0.0.1"` на
   `host="0.0.0.0"` и перезапустите:
   - `127.0.0.1` — «пускать только с этого компьютера», `0.0.0.0` — «пускать отовсюду»;
   - **Windows спросит** «Разрешить доступ?» (окно брандмауэра) — поставить галочку
     **«Частные сети»** и нажать **«Разрешить»**. Без прав администратора окно может не
     появиться — тогда см. «Частые проблемы»;
   - свой IP: Terminal в PyCharm → `ipconfig` → «IPv4-адрес», например `192.168.1.15`;
   - сосед сначала открывает в браузере `http://192.168.1.15:8000/docs`, потом вписывает
     адрес в `BASE_URL` в `client.py` и запускает его. Пусть добавит зверя в ваш зоопарк —
     хозяин видит в консоли сервера строку `POST /animals HTTP/1.1" 201`.

8. **Журнал запросов.** Обратите внимание на консоль сервера: на каждый запрос — строка с
   адресом клиента, методом, путём и кодом ответа. Вот так Космопорт «видел» все запросы
   учеников на уроках 3–7.

## Контрольная точка

У каждого ученика запущен свой `main.py`: в браузере открываются `/`, `/animals`,
`/animals/3`, `/animals/99` отвечает 404 с русским текстом, `/animals?planet=Мурлыка` — один
зверь, в `/docs` через **Try it out** добавляется новый зверь (201). Сосед по парте своим
`client.py` (с IP хозяина в `BASE_URL`) видит список зверей и добавляет в чужой зоопарк своего.

**Итоги курса (2–3 минуты).** Вспомните путь: список словарей (урок 1) → JSON (урок 2) → он же
по сети (уроки 3–5) → отправляем свои данные с ключом (урок 6) → квест (урок 7) → и наконец
пишем сервер сами. Любой сайт или приложение, у которого есть «данные с сервера», устроен из
этих же кирпичиков.

## Частые проблемы

- **`ModuleNotFoundError: No module named 'fastapi'`** — пакет поставлен не в тот
  интерпретатор. Ставить в терминале **PyCharm** (там уже включено окружение проекта) или через
  Settings → Python Interpreter того же проекта.
- **`TypeError: unsupported operand type(s) for |`** на строке `str | None` — Python старше 3.10.
  Обновить Python или написать `planet: str = ""` и проверять `if planet == "" or ...`.
- **Открыли `http://0.0.0.0:8000` — не работает.** Это адрес «слушать везде», а не адрес для
  браузера. Себе — `http://127.0.0.1:8000`, соседу — `http://<ваш IP>:8000`.
- **Поправил код, а ответ старый** — сервер не перезапущен. Stop → Run (или кнопка Rerun).
  Ученики часто запускают **второй** экземпляр, не остановив первый, — см. следующий пункт.
- **`[Errno 10048] ... only one usage of each socket address`** — порт 8000 уже занят: сервер
  уже запущен в другой вкладке Run (закрыть её — красный квадрат), или им пользуется другая
  программа (тогда `port=8001` и в `BASE_URL` соседа тоже 8001).
- **`/animals/random` отвечает 422** (задание 1) — маршрут стоит ниже `/animals/{animal_id}`:
  FastAPI проверяет маршруты сверху вниз, и «random» достался функции с номером.
- **422 при POST, хотя всё правильно** — в теле не тот тип или нет поля: читайте `detail` —
  там `loc` (где) и `msg` (что не так). `data=` вместо `json=` у клиента — тоже 422.
- **Сосед не может зайти, а у меня всё открывается:**
  1. в `uvicorn.run` всё ещё `host="127.0.0.1"` — заменить на `"0.0.0.0"` и перезапустить;
  2. неверный IP — проверить `ipconfig`; если адаптеров несколько, нужен тот, что с «Основным
     шлюзом» (Wi-Fi или Ethernet), а не VirtualBox/VPN;
  3. **брандмауэр Windows** блокирует входящие — при первом запуске нажали «Отмена». Исправить:
     Панель управления → Брандмауэр Защитника Windows → «Разрешить взаимодействие с приложением…»
     → найти `python.exe` → галочка «Частная». Если сеть в Windows помечена как **«Общедоступная»**,
     правило для частных сетей не сработает — нужна галочка «Публичная» или смена профиля сети
     (Параметры → Сеть → свойства Wi-Fi → «Частная»). Для этого нужны права администратора —
     попросите их заранее у администратора школы;
  4. компьютеры в разных сетях (один в Wi-Fi гостей, другой по кабелю) или в Wi-Fi включена
     «изоляция клиентов» — тогда по сети не получится, только `127.0.0.1` у себя.
- **`requests` у соседа падает с `ProxyError`**, а браузер открывает — на компьютере включён
  VPN или прокси, и `requests` отправляет запрос к `192.168.…` через него. Выключить VPN или
  запускать с переменной окружения `NO_PROXY=*` (Run → Edit Configurations → Environment variables).
- **Консоль сервера красная** — uvicorn пишет сообщения о запуске (`INFO: Started server
  process…`) в поток ошибок, и PyCharm красит их красным. Это не ошибки. Настоящая ошибка выглядит как `Traceback` и ответ `500 Internal Server
  Error` у клиента — например, `KeyError` в нашей функции.

## Дополнительно

- **Автоперезапуск.** `uvicorn.run("main:app", reload=True)` (строкой, а не объектом `app`)
  перезапускает сервер сам при каждом сохранении файла. Удобно, но на уроке может запутать —
  лучше показать в конце.
- **Почему 422, а не 400?** Это «Unprocessable Entity — запрос понятен, но данные не те».
  FastAPI так отвечает по умолчанию. Космопорт переделал ответ в 400 с русским текстом (файл
  `server/errors.py`) — так проще ученикам на уроках 3–7. Любой ответ сервера — решение его
  автора.
- **Порядок проверок в задании 7.** С моделью в аргументах FastAPI сначала проверяет тело, а
  уже потом вызывает функцию с проверкой ключа: неправильное тело без ключа даст 422, а не 401.
  Хороший повод обсудить, что сервер — это просто последовательность проверок.
- **Если в классе нет локальной сети** — можно выложить зоопарк в интернет так же, как
  Космопорт (Amvera, Render и т. п.), но это уже тема для отдельного занятия: регистрация,
  `requirements.txt`, адрес с HTTPS.
- **Что дальше.** Базы данных (SQLite — как у Космопорта для ключей и доски), сайты с HTML
  поверх своего API, Telegram-боты (бот — тоже клиент API), WebSocket для чатов.
