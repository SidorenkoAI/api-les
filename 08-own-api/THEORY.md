# Урок 8. Свой API на FastAPI — теория и разбор кода

Семь уроков мы были **клиентами**: отправляли запросы серверу «Космопорт» и разбирали его
ответы. Но кто-то же этот сервер написал! Кто-то решил, что по адресу `/planets/3` будет
планета, что на `/planets/Плутон` придёт 404, что у POST будет тело с ключом `"text"`.

Сегодня мы **по ту сторону**: пишем свой сервер — «Космический зоопарк» — и пускаем к нему
соседа по парте.

## Что нужно установить

В PyCharm внизу открой вкладку **Terminal** и введи:

```
pip install fastapi uvicorn
```

- **FastAPI** — библиотека, чтобы писать API: адреса, параметры, ответы.
- **uvicorn** — программа-сервер: она слушает сеть, принимает HTTP-запросы и передаёт их
  в FastAPI.

## Сервер — это программа, которая ждёт

Обычная программа выполняется сверху вниз и заканчивается. Сервер запускается и **не
заканчивается**: он ждёт запросов и на каждый отвечает. Поэтому после запуска `main.py`
в PyCharm ничего «не происходит» — программа работает, пока не нажмёшь красный квадрат **Stop**.

В консоли при запуске появится:

```
INFO:     Uvicorn running on http://0.0.0.0:8000 (Press CTRL+C to quit)
```

Открой в браузере http://127.0.0.1:8000 — это твой сервер на твоём компьютере.

**После каждой правки кода сервер нужно перезапустить** (Stop → Run). Иначе работает старая
версия, которая была загружена при запуске.

## Самый маленький API

```python
import uvicorn
from fastapi import FastAPI

app = FastAPI(title="Космический зоопарк")

@app.get("/")
def welcome():
    return {"message": "Добро пожаловать в Космический зоопарк!"}

if __name__ == "__main__":
    uvicorn.run(app, host="127.0.0.1", port=8000)
```

- `app = FastAPI(...)` — наше приложение, «сервер целиком». `title` — название для `/docs`.
- `@app.get("/")` — **маршрут**: «когда придёт GET-запрос на адрес `/`, вызови функцию ниже».
  Строка с `@` называется **декоратор** — она «приклеивает» функцию к адресу.
- Функция возвращает **словарь** — FastAPI сам превращает его в JSON. Помнишь `json.dumps` из
  урока 2? Здесь он происходит без нас.
- `uvicorn.run(app, ...)` — запустить сервер. `port=8000` — номер «двери», в которую стучатся
  клиенты, поэтому адрес — `http://127.0.0.1:8000`.
- `if __name__ == "__main__":` — «только если файл запустили кнопкой Run, а не импортировали».

## Разбор кода урока

### Данные зоопарка

```python
animals = [
    {"id": 1, "name": "Пушок", "species": "звёздный кот", "planet": "Мурлыка", "age": 3, "legs": 4},
    {"id": 2, "name": "Бульк", "species": "медуза-фонарик", "planet": "Аквамарина", "age": 12, "legs": 0},
    ...
]
```

Обычный список словарей — ровно такой, как на уроке 1. Данные живут **в памяти** программы:
перезапустил сервер — всё, что добавили, пропало, остались только эти звери.

### Список зверей и параметр запроса

```python
@app.get("/animals")
def list_animals(planet: str | None = None):
    result = []
    for animal in animals:
        if planet is None or animal["planet"].lower() == planet.lower():
            result.append(animal)
    return {"count": len(result), "animals": result}
```

Аргумент функции `planet` — это **параметр запроса**: `/animals?planet=Мурлыка`. На уроке 4 ты
передавал его через `params={"planet": "Мурлыка"}` — а вот как его получает сервер.

- `str | None` — «строка или ничего»; `= None` — значение по умолчанию. Значит, параметр
  **необязательный**: без него `/animals` вернёт всех зверей.
- Сравниваем через `.lower()` — чтобы `мурлыка` и `МУРЛЫКА` тоже находились.

Ответ — словарь: `count` и `animals`. Можно было вернуть просто список, но словарь удобнее:
потом можно добавить новые поля, и старые клиенты не сломаются.

### Один зверь: параметр пути и 404

```python
@app.get("/animals/{animal_id}")
def get_animal(animal_id: int):
    for animal in animals:
        if animal["id"] == animal_id:
            return animal
    raise HTTPException(status_code=404, detail=f"Зверя №{animal_id} в зоопарке нет")
```

- `{animal_id}` в адресе — **параметр пути**. Из `/animals/3` FastAPI возьмёт `3` и передаст
  в аргумент с тем же именем.
- `animal_id: int` — подсказка типа, и она работает: FastAPI сам переведёт `"3"` из адреса в
  число `3`. А на `/animals/abc` ответит **422** — «это не число». Мы эту проверку не писали!
- `return animal` внутри цикла — сразу ответ, дальше не ищем.
- Если цикл закончился — зверя нет. `raise HTTPException(...)` — «прервать функцию и ответить
  ошибкой». Клиент получит код **404** и JSON `{"detail": "Зверя №99 в зоопарке нет"}`.

Вот откуда на уроке 3 брался 404 «нет такой планеты»: в сервере Космопорта есть точно такой же
`raise`.

### Новый зверь: POST и модель

```python
class NewAnimal(BaseModel):
    name: str
    species: str
    planet: str
    age: int
    legs: int = 4


@app.post("/animals", status_code=201)
def add_animal(new: NewAnimal):
    animal = {
        "id": max(a["id"] for a in animals) + 1,
        "name": new.name,
        ...
    }
    animals.append(animal)
    return animal
```

- `NewAnimal` — **модель**: описание, каким должно быть тело запроса. Какие поля и каких типов.
  `legs: int = 4` — поле со значением по умолчанию, его можно не присылать.
- `@app.post` вместо `@app.get` — маршрут для метода POST. `status_code=201` — «создано», как у
  Космопорта при регистрации на уроке 6.
- Аргумент `new: NewAnimal` — FastAPI возьмёт **тело запроса** (тот самый `json=` у клиента),
  проверит его по модели и передаст в функцию. Поля — через точку: `new.name`, `new.age`.
- Номер нового зверя выдаёт **сервер**, а не клиент: на 1 больше самого большого. Иначе два
  соседа могли бы прислать зверей с одинаковым номером.

Если тело не подходит — нет поля, `"age": "старый"` вместо числа, — FastAPI **не вызовет**
функцию, а сразу ответит **422** и объяснит:

```json
{
  "detail": [
    {
      "type": "int_parsing",
      "loc": ["body", "age"],
      "msg": "Input should be a valid integer, unable to parse string as an integer",
      "input": "старый"
    }
  ]
}
```

`loc` — где ошибка (в теле, поле `age`), `msg` — что не так (по-английски). А вот строка `"4"`
подойдёт: FastAPI переведёт её в число 4.

### Страница `/docs`

Открой http://127.0.0.1:8000/docs. Это та же страница, что была у Космопорта: все маршруты,
параметры, модель тела, кнопка **Try it out**. Мы её не писали — FastAPI построил её по нашим
функциям, аннотациям и строкам документации (`"""..."""` под `def`). Теперь ты знаешь, откуда
она у Космопорта: его сервер тоже на FastAPI.

## Пускаем соседа: локальная сеть

Пока сервер слушает адрес `127.0.0.1` — это «только этот компьютер». Чтобы зашёл сосед,
меняем на `0.0.0.0` — «принимать запросы отовсюду»:

```python
uvicorn.run(app, host="0.0.0.0", port=8000)
```

1. **Узнай свой IP.** В Terminal PyCharm: `ipconfig`, строка «IPv4-адрес», например
   `192.168.1.15`. Это адрес твоего компьютера в сети класса.
2. **Разреши доступ.** При первом запуске Windows спросит, разрешить ли Python доступ к сети, —
   поставь галочку «Частные сети» и нажми «Разрешить». Это **брандмауэр**: он по умолчанию не
   пускает чужие запросы к твоему компьютеру. Правильно делает!
3. **Сосед** открывает в браузере `http://192.168.1.15:8000/docs`, а в `client.py` пишет
   `BASE_URL = "http://192.168.1.15:8000"`.

Сам ты по-прежнему открываешь `http://127.0.0.1:8000`. Адрес `http://0.0.0.0:8000` в браузере
не работает: `0.0.0.0` значит «слушать везде», это не адрес, куда можно зайти.

В консоли сервера на каждый запрос появляется строка:

```
INFO:     192.168.1.20:53412 - "POST /animals HTTP/1.1" 201 Created
```

Кто спросил (адрес соседа), что спросил (метод и путь) и что ответили (код). Так Космопорт видел
твои запросы на уроках 3–7.

## Клиент соседа: `client.py`

Клиент — то же самое, что мы писали весь курс: `requests.get`, `params=`, `requests.post`
с `json=`, проверка `status_code`. Новое только одно — ошибки FastAPI лежат в ключе `detail`
(у Космопорта был `error`), и `detail` бывает двух видов:

```python
def explain(response):
    detail = response.json()["detail"]
    if isinstance(detail, str):
        return detail
    problems = []
    for problem in detail:
        problems.append(f"{problem['loc'][-1]}: {problem['msg']}")
    return "; ".join(problems)
```

- строка — ошибку написали мы сами в `HTTPException` (например, 404);
- список — ошибка 422: FastAPI проверил данные, и каждая найденная проблема — словарь с `loc`
  и `msg`. `problem['loc'][-1]` — последний элемент, имя поля.

`isinstance(detail, str)` — «является ли `detail` строкой».

## Подробный разбор: путь запроса от клиента до функции

Что происходит, когда сосед выполняет `requests.get("http://192.168.1.15:8000/animals/3")`:

1. `requests` отправляет по сети на компьютер `192.168.1.15`, в «дверь» 8000, текст
   `GET /animals/3 HTTP/1.1`.
2. Брандмауэр Windows проверяет: можно ли пускать? Если разрешили — пропускает.
3. **uvicorn** слушает порт 8000, принимает запрос и передаёт его FastAPI.
4. **FastAPI** перебирает маршруты сверху вниз и ищет подходящий: метод GET, путь вида
   `/animals/{animal_id}` — подходит! Достаёт `"3"`, переводит в `int`.
5. Вызывает `get_animal(animal_id=3)`. Функция возвращает словарь.
6. FastAPI превращает словарь в JSON, добавляет код 200 и заголовок
   `content-type: application/json`.
7. uvicorn отправляет ответ обратно, а у соседа `response.json()` превращает JSON снова в словарь.

Словарь на сервере → JSON по сети → словарь у клиента. Весь курс в одной картинке.

## Подробный разбор: порядок маршрутов

FastAPI проверяет маршруты **сверху вниз** и берёт первый подходящий. Если сделать
`/animals/random` (задание 1) **ниже** `/animals/{animal_id}`, то запрос `/animals/random`
достанется функции с номером: `{animal_id}` подходит под любое слово. А «random» — не число,
и ответ будет 422. Правило: **точные адреса — выше, адреса с параметрами — ниже**.

## Подробный разбор: 422 или 400?

FastAPI по умолчанию отвечает на неверные данные кодом **422** и пишет по-английски. У
Космопорта на уроках 4 и 6 было **400** и русский текст — его автор специально настроил это
(файл `server/errors.py`). Какие коды и тексты отдаёт API — это решение того, кто его пишет.
Хороший API отвечает **одинаково** и **понятно** — чтобы клиент мог разобраться без автора.
