## Клиент, сервер, запрос и ответ

Когда ты открываешь сайт, твой компьютер **просит** страницу у другого компьютера — **сервера**.
Тот, кто просит, называется **клиентом**. Браузер — клиент. Сегодня наша программа на Python тоже
станет клиентом.

```
клиент (Python)   ── запрос: GET /planets/2 ──►   сервер «Космопорт»
                  ◄── ответ: 200 + JSON ───────
```

**Запрос** — это «дай мне вот это». Самый частый вид запроса — **GET** («получить»).
**Ответ** — это код ответа и содержимое (у нас всегда JSON).

**API** (*Application Programming Interface*) — это набор адресов, по которым программа может
что-то попросить у сервера, и правила, в каком виде придёт ответ. Наш API «Космопорт» умеет
рассказывать о планетах, инопланетянах и погоде.

## Подробный разбор: из чего состоит адрес (URL)

```
https://api-lessons-sidorenkoai.msk1.amvera.tech/planets/2
└─┬──┘   └──────────────┬──────────────────────┘└───┬────┘
протокол            домен (какой сервер)        путь (что именно)
```

- **протокол** `https` — на каком «языке» говорят клиент и сервер (буква *s* — «защищённо»);
- **домен** — имя сервера в интернете;
- **путь** — что именно мы просим у этого сервера: `/planets` — список планет,
  `/planets/2` — планету номер 2.

Открой эти адреса в браузере — увидишь JSON. А на странице
https://api-lessons-sidorenkoai.msk1.amvera.tech/docs можно попробовать любой запрос кнопками
**Try it out → Execute**.

## Подробный разбор: коды ответа

Сервер всегда отвечает числом — **кодом ответа**. По нему сразу понятно, получилось или нет.

| Код | Что значит | Когда бывает у нас |
|---|---|---|
| **200** | OK, всё хорошо | обычный успешный запрос |
| **404** | Not Found, не найдено | `/planets/99` — такой планеты нет; `/nope` — такого адреса нет |
| **400** | Bad Request, неверный запрос | `/aliens/abc` — вместо номера буквы |
| **500**, **503** | ошибка на сервере | сервер сломался или перезапускается |

Правило: коды **2xx** — успех, **4xx** — «ты попросил что-то не так», **5xx** — «проблема у
сервера».

## Разбор кода урока

### Шаг 1. Первый запрос

```python
import requests

BASE_URL = "https://api-lessons-sidorenkoai.msk1.amvera.tech"

response = requests.get(BASE_URL + "/")
print("Код ответа:", response.status_code)
```

- `BASE_URL` — адрес сервера. Он записан **один раз** в начале файла. Если сервер переедет на
  другой адрес, поменять нужно будет только эту строку.
- `requests.get(адрес)` отправляет GET-запрос и **ждёт**, пока сервер ответит. Результат —
  объект-ответ, мы кладём его в переменную `response` (часто пишут коротко: `r`).
- `response.status_code` — код ответа, число. Пишется **без скобок**: это не функция, а просто
  значение, которое лежит внутри ответа.

### Шаг 2. Текст или данные?

```python
print(type(response.text))   # <class 'str'>
data = response.json()
print(type(data))            # <class 'dict'>
print(data["message"])
```

- `response.text` — то, что прислал сервер, **в виде строки**. Это JSON-текст, как в файле на
  уроке 2. Взять из строки значение по ключу нельзя.
- `response.json()` — **разобрать** этот текст в словари и списки Python. Это то же самое, что
  `json.loads(response.text)`. Здесь скобки нужны: `json()` — это метод, он выполняет работу.

После `.json()` у тебя снова обычный словарь — работай с ним, как на уроках 1–2.

### Шаг 3. Список планет

```python
response = requests.get(BASE_URL + "/planets")
data = response.json()
planets = data["planets"]

for planet in planets:
    print(f'{planet["id"]:>2}. {planet["name"]:<12} {TYPE_NAMES[planet["type"]]}')
print("Всего планет:", data["count"])
```

Сервер прислал не список, а **словарь** с двумя ключами:

```json
{
  "count": 12,
  "planets": [
    {"id": 1, "name": "Терра-Нова", "type": "rocky"},
    {"id": 2, "name": "Кеплер-Б", "type": "rocky"},
    ...
  ]
}
```

Поэтому сам список — это `data["planets"]`. Хорошая привычка: прежде чем писать цикл, напечатай
ответ целиком (`print(data)`) и посмотри, как он устроен.

Заметь: в списке у планет только `id`, `name` и `type`. Сервер присылает **краткую** версию,
чтобы ответ был маленьким. Подробности — по отдельному адресу.

### Шаг 4. Карточка планеты и проверка кода ответа

```python
planet_id = input("\nВведи номер планеты: ").strip()
response = requests.get(f"{BASE_URL}/planets/{planet_id}")

if response.status_code == 200:
    planet = response.json()
    print(f'\n=== {planet["name"]} ===')
    ...
elif response.status_code == 404:
    print("Такой планеты нет. Сервер ответил:", response.json()["error"])
else:
    print("Что-то пошло не так, код ответа:", response.status_code)
```

- Адрес собираем f-строкой: номер, который ввёл пользователь, становится частью пути.
  Ввёл `2` — запрос уйдёт на `/planets/2`.
- Сервер «Космопорт» понимает в этом месте и **имя** планеты: `/planets/Мурлыка` тоже работает.
- Если планеты нет, сервер ответит кодом **404**, а в JSON будет не планета, а сообщение:
  `{"error": "Планета «99» не найдена. ..."}`. Если не проверить код и сразу написать
  `planet["temperature"]`, программа упадёт с `KeyError`.

Главное правило работы с API: **сначала проверь код ответа, потом бери данные.**

## Подробный разбор: почему запросы — это небыстро

Каждый `requests.get` — это путешествие: запрос летит по сети к серверу, сервер думает, ответ
летит обратно. Даже если это занимает 0,1 секунды, сто запросов — это уже 10 секунд. Поэтому
хорошие программы делают **как можно меньше запросов**. В задании 4 ты посчитаешь население
галактики, сделав по запросу на каждую планету, и замеришь время. А на уроке 4 узнаешь, как
получить то же самое одним запросом.

Замерить время можно так:

```python
import time

started = time.perf_counter()   # «включить секундомер»
...                             # что-то долгое
seconds = time.perf_counter() - started
print(f"Прошло {seconds:.2f} с")
```

## Ошибки, которые встречаются чаще всего

| Сообщение | Что случилось |
|---|---|
| `ModuleNotFoundError: No module named 'requests'` | Библиотека не установлена (см. «Подготовка») |
| `requests.exceptions.ConnectionError` | Нет интернета, опечатка в адресе или сервер недоступен |
| `requests.exceptions.MissingSchema` | В адресе нет `https://` |
| `KeyError: 'temperature'` | Пришла ошибка (404), а код ответа не проверили |
| `TypeError: string indices must be integers` | Берёшь ключ у `response.text` (строки) — нужен `response.json()` |
| `TypeError: 'int' object is not callable` | Написал `response.status_code()` — нужно без скобок |

## Что запомнить

- Программа-**клиент** отправляет **запрос** на **сервер**, сервер возвращает **ответ**: код + данные.
- `requests.get(адрес)` — отправить GET-запрос.
- `response.status_code` — код ответа: 200 — хорошо, 404 — не найдено.
- `response.text` — ответ строкой, `response.json()` — ответ, разобранный в словари и списки.
- Сначала проверяем код ответа, потом берём данные.
- Каждый запрос — это время. Чем меньше запросов, тем быстрее программа.
