# Урок 5. Погода на планетах — теория и разбор кода

Сегодня мы получим с сервера прогноз погоды на планете — по часам, на целые сутки — и превратим
кучу чисел в понятные ответы: когда теплее всего, когда буря, когда безопасно выйти из корабля.
А в конце нарисуем график.

## Подробный разбор: как устроен прогноз

Открой в браузере https://api-lessons-sidorenkoai.msk1.amvera.tech/weather?planet=2. Сокращённо
ответ выглядит так:

```json
{
  "planet": {"id": 2, "name": "Кеплер-Б"},
  "start": "2026-11-19",
  "days": 1,
  "timezone": "UTC+7",
  "units": {"temperature": "°C", "wind": "м/с", ...},
  "hourly": {
    "time":        ["2026-11-19T00:00", "2026-11-19T01:00", "2026-11-19T02:00", ...],
    "temperature": [-39.6, -48.7, -48.6, ...],
    "wind":        [9.7, 9.3, 9.8, ...],
    "storm":       [false, false, false, ...]
  }
}
```

Здесь нет словаря «час → погода». Вместо этого — четыре **отдельных списка** одинаковой длины
(24 значения на сутки). Погода в один и тот же час — это элементы **с одинаковым номером**:

```
номер i         0                  1                  2
time         "2026-11-19T00:00"  "2026-11-19T01:00"  "2026-11-19T02:00"
temperature   -39.6               -48.7               -48.6
wind            9.7                 9.3                 9.8
storm         false               false               false
```

Такие списки называют **параллельными массивами**. Это как столбцы таблицы. Так присылают
данные настоящие погодные сервисы (например, open-meteo.com): получается короче, чем повторять
`"time"`, `"temperature"`… в каждом часе.

Прогноз зависит от планеты и **даты**: сегодня у всего класса одинаковые числа, а завтра будут
другие. Параметры запроса: `planet` (номер или имя), `days` (сколько суток, от 1 до 7),
`start` (с какой даты, по умолчанию — сегодня).

## Разбор кода урока

### Шаг 1. Получаем прогноз

```python
def load_forecast(planet, days):
    """Скачать прогноз. Если не получилось — объяснить почему и вернуть None."""
    try:
        response = requests.get(BASE_URL + "/weather", params={"planet": planet, "days": days}, timeout=10)
    except requests.RequestException as error:
        print("Нет связи с сервером:", error)
        return None
    if response.status_code != 200:
        print("Сервер ответил ошибкой:", response.json()["error"])
        return None
    return response.json()


forecast = None
while forecast is None:
    planet = input("Для какой планеты прогноз (имя или номер)? ").strip()
    forecast = load_forecast(planet, 1)
```

Всё знакомо по уроку 4: параметры словарём, `timeout`, `try`/`except`, проверка кода ответа.
Функция возвращает `None`, если не получилось, — и цикл `while` спрашивает планету ещё раз.

### Шаг 2. Раскладываем по спискам

```python
hourly = forecast["hourly"]
times = hourly["time"]
temps = hourly["temperature"]
winds = hourly["wind"]
storms = hourly["storm"]

hours = []
for moment in times:
    hours.append(moment[11:16])
```

Короткие имена списков сделают код дальше гораздо читаемее. Время приходит полностью:
`"2026-11-19T15:00"`. Нам хватит часов — берём **срез** строки `moment[11:16]`:

```
"2026-11-19T15:00"
 ├─── 0–10 ──┤├11–15┤
 2026-11-19T  15:00   → moment[11:16] == "15:00"
```

Номера символов начинаются с 0: символы 0–10 — это дата и буква `T`, а с 11-го по 15-й —
`1`, `5`, `:`, `0`, `0`. Конец среза (16) в него не входит, как и в `range`.

### Шаг 3. `zip` — идём по всем спискам сразу

```python
for hour, temp, wind, storm in zip(hours, temps, winds, storms):
    mark = "  БУРЯ!" if storm else ""
    print(f"{hour}  {temp:>9}  {wind:>10}{mark}")
```

`zip` (по-английски «застёжка-молния») берёт **по одному элементу из каждого списка** и выдаёт их
вместе: сначала нулевые, потом первые, потом вторые… В переменных `hour`, `temp`, `wind`, `storm`
на каждом шаге цикла — данные об одном и том же часе.

То же самое можно написать через номера, но читать труднее:

```python
for i in range(len(hours)):
    print(hours[i], temps[i], winds[i], storms[i])
```

`mark = "  БУРЯ!" if storm else ""` — короткая запись `if`/`else` в одну строку: если буря —
одно значение, иначе — другое.

### Шаг 4. Максимум вместе с номером

```python
warmest = max(temps)
warmest_i = temps.index(warmest)
print(f"Самый тёплый час: {hours[warmest_i]}, {warmest} °C")
```

`max(temps)` даёт самую высокую температуру, но не говорит, **в какой час** она была. Зато
`temps.index(значение)` находит **номер** этого значения в списке. А по номеру можно взять элемент
из любого параллельного списка — время из `hours`, ветер из `winds`.

Среднее — сумма, делённая на количество: `sum(temps) / len(temps)`.

### Шаг 5. Отбор по условию

```python
storm_hours = []
for hour, storm in zip(hours, storms):
    if storm:
        storm_hours.append(hour)
```

Это шаблон «отбор в новый список» из урока 1, только теперь с `zip`: проверяем один список
(`storms`), а берём значения из другого (`hours`).

### Шаг 6. Поиск с условием: лучший час для выхода

```python
best_i = None
for i in range(len(hours)):
    if not storms[i] and (best_i is None or winds[i] < winds[best_i]):
        best_i = i
```

Ищем час **без бури** с **самым слабым ветром**. Встроенные `min` и `max` про условия не знают,
поэтому пишем поиск сами:

- `best_i = None` — «пока ничего не нашли»;
- `not storms[i]` — в этот час нет бури;
- `best_i is None or winds[i] < winds[best_i]` — это первый подходящий час или ветер в нём
  слабее, чем в лучшем найденном.

Если после цикла `best_i` так и остался `None`, значит, весь день буря.

### Шаг 7. Рисуем график

```python
import matplotlib.pyplot as plt

plt.figure(figsize=(10, 5))
plt.plot(hours, temps, marker="o", linewidth=2, label="температура")
plt.scatter(storm_hours, storm_temps, color="red", marker="X", s=120, zorder=3, label="буря")

plt.title(f"Температура на планете {name}, {forecast['start']}")
plt.xlabel("Время")
plt.ylabel("Температура, °C")
plt.xticks(rotation=45)
plt.grid(alpha=0.3)
plt.legend()
plt.tight_layout()
plt.savefig("forecast.png", dpi=100)
plt.show()
```

| Команда | Что делает |
|---|---|
| `plt.figure(figsize=(10, 5))` | новый рисунок 10×5 дюймов |
| `plt.plot(x, y)` | линия по точкам: `x` — по горизонтали, `y` — по вертикали |
| `marker="o"` | кружок на каждой точке |
| `label="..."` | подпись линии для легенды |
| `plt.scatter(x, y)` | отдельные точки без линии (у нас — крестики на часах бури) |
| `zorder=3` | нарисовать поверх линии |
| `plt.title`, `plt.xlabel`, `plt.ylabel` | заголовок и подписи осей |
| `plt.xticks(rotation=45)` | повернуть подписи под осью X, чтобы не налезали |
| `plt.grid(alpha=0.3)` | бледная сетка |
| `plt.legend()` | легенда — какой цвет что значит |
| `plt.tight_layout()` | подвинуть всё, чтобы подписи не обрезались |
| `plt.savefig("forecast.png")` | сохранить в файл |
| `plt.show()` | показать окно с графиком |

Важно: `savefig` — **до** `show`. Когда окно графика закрывают, рисунок исчезает, и сохранять
будет уже нечего. И ещё: пока окно открыто, программа ждёт и дальше не идёт.

Для `scatter` нужен список температур **только в часы бури** — его собираем так же, как
`storm_hours`. Списки `x` и `y` для графика всегда должны быть одной длины.

## Подробный разбор: срезы для нескольких суток

Если попросить `days=2`, в каждом списке будет 48 значений: первые 24 — сегодня, следующие 24 —
завтра. Достать «завтра» помогает срез:

```python
tomorrow_temps = temps[24:48]
```

А неделю (`days=7`, 168 значений) можно разрезать на сутки циклом с шагом 24:

```python
for start in range(0, len(temps), 24):
    day = temps[start:start + 24]
```

## Ошибки, которые встречаются чаще всего

| Сообщение | Что случилось |
|---|---|
| `ModuleNotFoundError: No module named 'matplotlib'` | Библиотека не установлена (см. «Подготовка») |
| `ValueError: x and y must have same first dimension` | Списки для `plot` или `scatter` разной длины |
| `ValueError: max() arg is an empty sequence` | `max` или `min` от пустого списка — проверь `if список:` |
| `ValueError: 15.5 is not in list` | `index` ищет значение, которого в этом списке нет — перепутал списки |
| Пустой `forecast.png` | `savefig` вызван после `show` |
| Программа «висит» после графика | Ждёт, пока закроешь окно с графиком |

## Что запомнить

- Параллельные массивы — несколько списков одной длины, элементы с одинаковым номером относятся
  к одному и тому же часу.
- `zip(a, b, c)` — идти по нескольким спискам сразу.
- `список.index(значение)` — номер элемента; по номеру берём данные из других списков.
- Поиск с условием — цикл по номерам и переменная «лучший найденный» (`None` в начале).
- Срезы `[24:48]` — кусок списка, например «завтра».
- График: `plot` → подписи → `savefig` → `show`.
