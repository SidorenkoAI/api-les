## Лёгкие

### 1. Полная карточка планеты

Напиши функцию `print_card(planet)`. Она печатает **все** сведения о планете в аккуратном виде:

```
=== Аквамарина ===
Тип: океанская
Гравитация: 1.1 g, радиус: 7 200 км
Температура: от 5 до 28 °C
Луны: нет
Вода: есть
Атмосфера: азот, кислород
Население: 56 000
Открыта: 2069-06-21
Один сплошной океан без единого острова. ...
```

Программа спрашивает имя планеты и печатает её карточку.

- Если список лун пустой, печатай «нет». Как проверить, что список пуст? (`len(...) == 0` или
  просто `if not planet["moons"]`.)
- Вместо `True`/`False` для воды — «есть»/«нет».
- Число с пробелами между тысячами: `f"{56000:,}"` даёт `56,000`, осталось заменить запятую
  на пробел методом `.replace()`.

### 2. Средняя температура

Для каждой планеты посчитай среднюю температуру: `(min + max) / 2`. Напечатай список планет со
средней температурой, а в конце — среднюю температуру по всей галактике.

- Температура лежит во вложенном словаре — как достать `min`?
- Для средней по галактике: сложи средние всех планет и раздели на их количество.
- `round(число, 1)` — округлить до одного знака после запятой.

### 3. Поиск без учёта регистра

Сейчас справочник не найдёт планету, если ввести `кеплер-б` или ` Кеплер-Б ` с пробелами.
Исправь поиск. А ещё сделай так, чтобы программа спрашивала снова и снова, пока не введут пустую
строку.

- `.lower()` делает все буквы маленькими, `.strip()` убирает пробелы по краям.
- Привести к одному виду нужно **обе** строки — и введённую, и имя планеты.
- Бесконечный цикл `while True:` и выход из него — `break`, когда строка пустая.

## Средние

### 4. Рейтинги

Напечатай три рейтинга, в каждом — первые три места:
- больше всего лун;
- самые лёгкие планеты (наименьшая гравитация);
- самые большие планеты (по радиусу).

- `sorted(planets, key=...)`. Для лун ключ должен вернуть не список лун, а **количество**.
- По возрастанию или по убыванию? Где нужен `reverse=True`?
- Три рейтинга печатаются одинаково — может, вынести печать в функцию?

### 5. Планеты по типам

Собери словарь, где ключ — тип планеты, а значение — список имён планет этого типа:

```
каменная: Терра-Нова, Кеплер-Б, Кварцелла
газовый гигант: Гигантус, Нимбус
...
```

- Начни с пустого словаря `by_type = {}`.
- Для каждой планеты: если такого типа ещё нет в словаре — создай для него пустой список. Потом
  добавь имя в этот список.
- Чтобы печатать по-русски, пригодится словарь `TYPE_NAMES` из урока.

### 6. Газы в атмосфере

Посчитай, на скольких планетах встречается каждый газ: `азот — 8`, `кислород — 4`… Какой газ
встречается чаще всего?

- Это **словарь-счётчик**: ключ — газ, значение — сколько раз встретился.
- Два вложенных цикла: по планетам и по газам атмосферы каждой планеты.
- Если газа ещё нет в счётчике — значение `0`, потом `+ 1`. Короче: `counter.get(gas, 0) + 1`.
- Самый частый газ: `max(counter, key=counter.get)` — или найди максимум циклом, как в уроке.

### 7. Чья это луна?

Программа спрашивает название луны и отвечает, вокруг какой планеты она вращается:
`Бублик — луна планеты Гигантус`. А ещё печатает все луны галактики по алфавиту.

- Удобно заранее собрать словарь «луна → имя планеты». Как его заполнить двумя циклами?
- Список всех лун: пустой список и `.extend()` (добавить сразу несколько элементов) или `append`
  во вложенном цикле. Потом `sorted()`.
- Что ответить, если такой луны нет?

## Посложнее

### 8. Сравнение двух планет

Программа спрашивает имена двух планет и печатает таблицу сравнения:

```
                 Терра-Нова    Кеплер-Б
гравитация              1.0        1.7  ←
радиус, км             6400       9100  ←
лун                       1          2  ←
мин. темп.              -10 ←      -80
макс. темп.              30         35  ←
население           2400000 ←    12500
```

Стрелка показывает, у кого значение больше.

- Сначала напиши функцию поиска планеты по имени (из задания 3) — пригодится.
- Строки таблицы удобно описать списком пар: `("гравитация", "gravity")`. Но как быть с лунами
  (нужна длина списка) и температурой (вложенный словарь)? Можно сделать функцию `value(planet, key)`,
  которая разбирает особые случаи.
- Выравнивание колонок: `f"{текст:<15}"` и `f"{число:>10}"`.

### 9. Пригодность для жизни

Придумай систему баллов «насколько планета подходит для людей» и выведи рейтинг всех планет:

- есть вода — +2;
- в атмосфере есть кислород — +2;
- температура от −50 до +50 (и минимум, и максимум внутри этого диапазона) — +2;
- гравитация от 0.5 до 1.5 — +1;
- на планете уже кто-то живёт — +1.

Напечатай планеты по убыванию баллов, а для лучших — за что они получили баллы.

- Функция `score(planet)` возвращает число баллов. Её же можно передать в `sorted` как `key`!
- Есть ли кислород: `"кислород" in planet["atmosphere"]`.
- Двойное сравнение в Python пишется красиво: `0.5 <= g <= 1.5`.
- Совпадает ли твой рейтинг с тем, что ты ожидал(а), читая описания планет?
