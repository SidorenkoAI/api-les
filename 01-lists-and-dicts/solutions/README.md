# Эталонные решения к заданиям урока 1

Каждый файл — отдельная готовая программа для одного задания из [EXERCISES.md](../EXERCISES.md).
Рядом лежит копия `planets_data.py`, поэтому любой файл можно запустить прямо из этой папки
(в PyCharm — правой кнопкой → Run).

| Файл | Задание | Что тренирует | Что ввести для проверки |
|---|---|---|---|
| [01_planet_card.py](01_planet_card.py) | Полная карточка планеты | функция, пустой список, `if`/`else`, форматирование чисел | `Аквамарина` (нет лун) |
| [02_average_temperature.py](02_average_temperature.py) | Средняя температура | вложенный словарь, накопление суммы, `round` | — |
| [03_case_insensitive_search.py](03_case_insensitive_search.py) | Поиск без учёта регистра | `.lower()`, `.strip()`, `while True` + `break`, функция с `return` | `кеплер-б`, потом пустая строка |
| [04_ratings.py](04_ratings.py) | Рейтинги | `sorted` с `key`, `reverse`, срез, функция как параметр | — |
| [05_planets_by_type.py](05_planets_by_type.py) | Планеты по типам | словарь списков (группировка) | — |
| [06_atmosphere_gases.py](06_atmosphere_gases.py) | Газы в атмосфере | словарь-счётчик, `.get(key, 0)`, вложенный цикл, максимум | — |
| [07_whose_moon.py](07_whose_moon.py) | Чья это луна? | словарь «обратного поиска», `.extend()`, `in` | `Бублик` |
| [08_compare_planets.py](08_compare_planets.py) | Сравнение двух планет | функции, список пар, особые случаи, выравнивание | `Терра-Нова`, `Кеплер-Б` |
| [09_habitability.py](09_habitability.py) | Пригодность для жизни | функция-ключ для `sorted`, `in` для списка, двойное сравнение | — |

Ожидаемые ответы, чтобы быстро проверить ученика:

- средняя температура по галактике — **−10.8 °C**; самая тёплая в среднем — Пеклон (315 °C);
- больше всего лун — Гигантус (8), Нимбус (4), Кварцелла (3); самая лёгкая — Кварцелла (0.4 g);
- азот — на 8 планетах, кислород — на 4; всего лун — 26;
- по баллам пригодности (задание 9) делят первое место Терра-Нова, Аквамарина, Мурлыка, Джунгла
  (по 8 баллов). Порядок между ними зависит от сортировки — это нормально.
