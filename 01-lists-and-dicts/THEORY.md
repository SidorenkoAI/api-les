# Урок 1. Списки и словари — теория и разбор кода

На этом уроке мы собираем «Справочник галактики»: программу, которая знает всё о 12 планетах
галактики «Космопорт», печатает их таблицу и отвечает на вопросы. Заодно вспоминаем списки,
словари и циклы — они понадобятся на каждом следующем уроке.

Почему это важно? Через два урока мы начнём получать данные **с сервера в интернете**. Почти все
сервисы в мире — погода, карты, игры, соцсети — отдают данные в виде списков и словарей, вложенных
друг в друга. Кто уверенно в них ориентируется, тот может работать с любым из этих сервисов.

## Подробный разбор: одна планета — это словарь

**Словарь** хранит пары «ключ → значение». Ключ — это «название поля», по нему значение и достаём:

```python
planet = {
    "name": "Кеплер-Б",
    "gravity": 1.7,
    "moons": ["Тик", "Так"],
    "temperature": {"min": -80, "max": 35},
    "has_water": True,
}

print(planet["name"])      # Кеплер-Б
print(planet["gravity"])   # 1.7
```

Значения бывают любого типа. Здесь есть строка, дробное число, логическое значение — и ещё
**список** (`moons`) и **словарь** (`temperature`). Данные, вложенные друг в друга, — обычное дело.

Как достать то, что лежит глубоко? **Шаг за шагом, слева направо:**

```python
planet["moons"]                # ['Тик', 'Так']        — это список
planet["moons"][0]             # 'Тик'                 — первый элемент списка
len(planet["moons"])           # 2                     — длина списка

planet["temperature"]          # {'min': -80, 'max': 35} — это словарь
planet["temperature"]["max"]   # 35                    — значение по ключу "max"
```

Если запутался — разбей на части и напечатай промежуточный результат:

```python
temperature = planet["temperature"]
print(temperature)          # {'min': -80, 'max': 35}
print(temperature["max"])   # 35
```

### Полезные приёмы со словарём

```python
planet.keys()                   # все ключи: name, gravity, moons, ...
"moons" in planet               # True — есть ли такой ключ
planet.get("rings")             # None — ключа нет, но ошибки не будет
planet.get("rings", "нет")      # 'нет' — запасное значение
for key, value in planet.items():
    print(key, "→", value)      # перебрать все пары
```

Обычное `planet["rings"]` при отсутствии ключа падает с ошибкой `KeyError`. А `.get()` спокойно
возвращает `None` или запасное значение. Это пригодится, когда данные приходят из интернета и
какого-то поля может не оказаться.

## Подробный разбор: много планет — список словарей

В файле `planets_data.py` лежит **список**, каждый элемент которого — словарь-планета:

```python
planets = [
    {
        "id": 1,
        "name": "Терра-Нова",
        ...
    },
    {
        "id": 2,
        "name": "Кеплер-Б",
        ...
    },
    ...
]
```

Квадратная скобка в самом начале — это список. Фигурные скобки — словари внутри него.

```python
len(planets)             # 12 — сколько планет
planets[0]               # первая планета (целый словарь)
planets[0]["name"]       # 'Терра-Нова'
planets[-1]["name"]      # 'Джунгла' — последняя
```

Частая ошибка — `planets["name"]`. У **списка** нет ключей, только номера (индексы). Сначала нужно
выбрать одну планету, а уже у неё брать ключ.

## Разбор кода урока

### Импорт данных

```python
from planets_data import planets
```

Файл `planets_data.py` лежит рядом с `main.py`. Python находит его и берёт оттуда переменную
`planets`. Так данные не мешают читать программу.

### Шаг 1. Таблица планет

```python
for planet in planets:
    type_name = TYPE_NAMES[planet["type"]]
    moons_count = len(planet["moons"])
    print(f'{planet["id"]:>2}. {planet["name"]:<12} {type_name:<16} лун: {moons_count}')
```

- `for planet in planets` — на каждом шаге цикла в переменной `planet` лежит **одна планета,
  то есть словарь**. Не номер!
- `TYPE_NAMES[planet["type"]]` — двойной поиск. Сначала берём у планеты тип (например, `"gas"`),
  потом по этому коду находим русское название в словаре `TYPE_NAMES` (`"газовый гигант"`).
  Словарь работает как таблица перевода.
- `:<12` в f-строке — «выровнять по левому краю в поле шириной 12 символов», `:>2` — по правому
  краю в поле из 2 символов. Поэтому колонки таблицы ровные.
- Внутри f-строки одинарные кавычки снаружи и двойные внутри: `f'{planet["name"]}'`.

### Шаг 2. Поиск максимума

```python
heaviest = planets[0]
for planet in planets:
    if planet["gravity"] > heaviest["gravity"]:
        heaviest = planet
```

Идея: «пока что самая тяжёлая — первая планета». Дальше смотрим все планеты по очереди: если
встретили тяжелее — она становится новым чемпионом. В конце в `heaviest` лежит победитель.

Мы запоминаем **всю планету**, а не только число гравитации. Поэтому потом можно напечатать и её
имя, и любые другие поля.

### Шаг 3. Отбор в новый список

```python
with_water = []
for planet in planets:
    if planet["has_water"]:
        with_water.append(planet["name"])
print("Вода есть на планетах:", ", ".join(with_water))
```

Шаблон «начали с пустого списка → в цикле добавляем подходящее». `planet["has_water"]` уже `True`
или `False`, поэтому `== True` писать не нужно.

`", ".join(список)` склеивает список строк в одну строку через `", "`. Работает только для списка
строк.

### Шаг 4. Накопление суммы

```python
total_moons = 0
for planet in planets:
    total_moons += len(planet["moons"])
```

Шаблон «начали с нуля → в цикле прибавляем». `len(planet["moons"])` — сколько лун у этой планеты
(у Аквамарины — 0, список пустой).

### Шаг 5. Сортировка по полю

```python
def by_population(planet):
    return planet["population"]

top = sorted(planets, key=by_population, reverse=True)
```

Числа или строки Python сравнивать умеет. А как сравнить две планеты? Непонятно: по имени? по
размеру? Поэтому мы **подсказываем**: `key=by_population` — «чтобы сравнить две планеты, сравни их
население». Python вызывает `by_population` для каждой планеты и сортирует по полученным числам.

- `reverse=True` — от большего к меньшему.
- `top[:3]` — **срез**: первые три элемента списка.
- `sorted` возвращает **новый** список, а исходный `planets` не меняется.

То же самое короче: `sorted(planets, key=lambda p: p["population"], reverse=True)`. `lambda` —
маленькая функция без имени, «по планете `p` вернуть `p["population"]`».

### Шаг 6. Поиск по имени

```python
found = None
for planet in planets:
    if planet["name"] == name:
        found = planet
        break

if found is None:
    print("Такой планеты нет в справочнике.")
```

`None` значит «пока ничего не нашли». Как только нашли — запоминаем планету и выходим из цикла
командой `break`: дальше искать незачем. После цикла проверяем, нашли ли что-нибудь.

## Подробный разбор: встроенные помощники

Многие циклы из урока Python умеет делать одной строкой. Пользоваться ими можно, когда ты уже
понимаешь, какой цикл стоит за каждой из них:

```python
max(planets, key=by_population)                 # самая населённая планета
min(planets, key=lambda p: p["gravity"])        # самая лёгкая
sum(len(p["moons"]) for p in planets)           # всего лун
[p["name"] for p in planets if p["has_water"]]  # имена планет с водой (списковое включение)
```

## Что запомнить

- Одна запись (планета, человек, город) — **словарь**. Много записей — **список словарей**.
- Глубокие данные достаём по шагам: `planet["temperature"]["max"]`.
- Цикл `for planet in planets` даёт по одному словарю за шаг.
- Четыре шаблона цикла: **найти максимум**, **отобрать в список**, **посчитать сумму**,
  **найти по условию** (с `break`).
- `sorted(..., key=функция)` — сортировка по нужному полю.
