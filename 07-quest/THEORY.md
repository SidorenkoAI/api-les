# Урок 7. Квест «Спасение станции» — правила и подготовка

На станции «Космопорт» авария: шлюз заперт, связь перехвачена, нужен сигнал спасения. Пройди
пять шагов быстрее всех! Ответ на каждый шаг спрятан в данных API — найди его и **посчитай
программой**. Таблица лидеров — на проекторе.

## Правила

- Время идёт у всех с момента, когда учитель нажал «Старт».
- **Неверный ответ — +30 секунд** к времени. **Подсказка — +60 секунд** (если попросить ту же
  подсказку ещё раз — бесплатно).
- Отвечать можно не чаще раза в секунду. Подбирать ответ наугад — очень дорого.
- У каждого **свой вариант**: числа в заданиях зависят от твоего ключа. Ответ соседа тебе
  не подойдёт. А вот помогать друг другу идеями — можно.

## Что нужно

- Файл `key.txt` с ключом из урока 6 — скопируй его в папку урока 7.
- **Пульт** — `main.py` (его выдаст учитель): показывает задание, отправляет ответы, берёт
  подсказки, показывает таблицу лидеров.
- **Свои программы** — по одной на шаг: `step1.py`, `step2.py`… Пульт ничего не считает — это
  твоя работа.

## Как устроен квест в API

| Запрос | Что делает |
|---|---|
| `GET /quest` + ключ | текущее задание |
| `POST /quest/answer` + ключ, тело `{"answer": ...}` | ответ на текущий шаг |
| `POST /quest/hint` + ключ | подсказка (+60 с) |
| `GET /leaderboard` | таблица лидеров (ключ не нужен) |

Ответ `GET /quest` во время игры:

```json
{
  "status": "playing",
  "step": 2,
  "total": 5,
  "title": "Проверка экипажа",
  "task": "Бортовой компьютер проверяет экипаж. Запроси 50 инопланетян с seed=420 и посчитай, ...",
  "data": {"count": 50, "seed": 420, "skill": "ремонт двигателей"},
  "hint": null,
  "time": 312,
  "penalty": 30
}
```

- `task` — задание для человека;
- **`data`** — те же числа и слова, но для программы. Не переписывай `seed` руками из текста —
  возьми его из `data`: так не ошибёшься;
- `hint` — подсказка, если ты её уже брал, иначе `null` (в Python — `None`);
- `time` — твоё время в секундах вместе со штрафами.

Пока учитель не нажал «Старт», сервер отвечает **409**: «Квест ещё не начался». Когда пройдёшь
все шаги — `"status": "finished"` и твоё итоговое время.

Ответ на `POST /quest/answer`:

```json
{"correct": true, "step": 3, "finished": false, "message": "Верно! Переходи к шагу 3 из 5: GET /quest"}
```

## Что вспомнить к каждому шагу

### Шаг 1 — рекорд среди планет

Нужно найти планету, у которой какое-то поле самое большое или самое маленькое. Два пути:

- **попросить сервер** отсортировать: `/planets?sort=moons&order=desc` — первая в списке и есть
  рекордсмен (урок 4). Сервер сортирует не по всем полям — смотри `/docs`;
- **найти самому**: `/planets?full=true` — все планеты целиком, а дальше поиск максимума
  циклом (урок 1) или `max(planets, key=...)`.

У `moons` в планете — **список** лун, сравнивать нужно его длину: `len(planet["moons"])`.
У температуры — вложенный словарь: `planet["temperature"]["min"]`.

### Шаг 2 — подсчёт по инопланетянам

Помнишь `seed` из урока 4? Одинаковый `seed` — одинаковый ответ, поэтому у тебя и у сервера
будут одни и те же 50 инопланетян. Параметры — словарём `params=`. У каждого инопланетянина
есть список `skills`; проверка — `"телепатия" in alien["skills"]`.

### Шаг 3 — прогноз погоды

`/weather` из урока 5. Нужна **дата из задания**, а не сегодняшняя: параметр `start`.
Температуры — в `["hourly"]["temperature"]`, среднее — `sum(...) / len(...)`, затем `round()`.

### Шаг 4 — шифр Цезаря

**Шифр Цезаря** — каждую букву заменяют на букву, которая стоит в алфавите на несколько позиций
дальше. Со сдвигом 3: а → г, б → д, в → е… Юлий Цезарь так шифровал военные письма.

Чтобы **расшифровать**, нужно сдвинуть каждую букву **назад**:

```python
ALPHABET = "абвгдеёжзийклмнопрстуфхцчшщъыьэюя"   # 33 буквы, с «ё»

number = ALPHABET.index("г")            # 3 — номер буквы в алфавите (с нуля)
ALPHABET[(number - 3) % 33]             # "а"
```

Зачем `% 33`? Алфавит идёт **по кругу**: после «я» снова «а». Если сдвинуть «а» (номер 0) назад
на 3, получится номер −3 — такой буквы нет. Остаток от деления это чинит:

```python
(0 - 3) % 33      # 30 → "э"
(32 + 1) % 33     # 0  → "а" (после «я» — снова «а»)
```

В Python остаток от деления на 33 **всегда** от 0 до 32, даже для отрицательных чисел.

Сдвиг в задании — «гравитация × 10». `1.7 * 10` — это `17.0`: дробное число. А номер буквы в
строке должен быть целым, иначе `TypeError: string indices must be integers`. Поэтому —
`round(gravity * 10)`.

Пробелы не шифруются: если символа нет в алфавите, оставляй его как есть.

### Шаг 5 — сигнал спасения

Две вещи из прошлых уроков: `/aliens/random` с параметром `planet` (урок 4) — найти самого
старшего жителя, и `POST /board` (урок 6) — отправить его позывной на доску. Только после этого
отправляй ответ: станция проверит, что сигнал на доске есть.

## Подробный разбор: `round` и `int`

| Число | `int(x)` | `round(x)` |
|---|---|---|
| `17.0` | 17 | 17 |
| `-79.67` | −79 (просто отбрасывает дробь) | −80 (до ближайшего целого) |
| `2.5` | 2 | 2 (!) |
| `3.5` | 3 | 4 |

`int` отрезает дробную часть, `round` округляет до ближайшего целого. Половинки `round`
округляет до **чётного** — так меньше накапливается ошибка, когда складывают много округлённых
чисел. В квесте сервер примет на шаге 3 и `round`, и `int`.

## Подробный разбор: `textwrap` в пульте

Тексты заданий длинные, и в консоли они уезжают за край экрана. Модуль `textwrap` режет текст на
строки нужной ширины, не разрывая слова:

```python
import textwrap

print(textwrap.fill(quest["task"], width=90))
```

## Подробный разбор: `requests.Session`

Когда запросов много, удобно завести **сессию**:

```python
session = requests.Session()
session.headers["X-API-Key"] = key           # заголовок — один раз для всех запросов

quest = session.get(BASE_URL + "/quest", timeout=10).json()
session.post(BASE_URL + "/quest/answer", json={"answer": 7}, timeout=10)
```

У сессии два плюса: заголовки (ключ) задаются один раз, и сессия **не открывает новое
соединение** для каждого запроса — запросы идут заметно быстрее. Проверишь в задании 4.
