Как устроена планета

Карта и координаты

Планета — это клетки, как тетрадь в клетку. Каждая клетка — пара чисел (x, y).

x растёт на восток → (вправо)
y растёт на север ↑ (вверх)

🏠 База — клетка (0, 0) в юго-западном углу. Отсюда ровер стартует.

☁️ Сначала вся карта в тумане. Что вокруг — узнаёшь только сканером.

Как на графике в математике: вправо и вверх — больше.

5
Пульт управления

Пять запросов — и ты пилот

GET/rover/scan📡 Где ровер и что на соседних клетках
POST/rover/move🛞 Проехать одну клетку. Тело: {"dir": "north"} — north, east, south или west
POST/rover/home🚚 Эвакуатор: вернуть ровер на базу. Находки остаются у тебя
GET/rover/diary📜 Страницы дневника, которые ты нашёл
GET/rover/map🗺️ Карта всего класса — ключ не нужен

Все запросы ровера — с личным ключом из урока 6: headers = {"X-API-Key": key}. Ключ лежит в key.txt — скопируй его в папку с заданиями.

Движение

Шаг на одну клетку

def move(direction):
    r = requests.post(BASE_URL + "/rover/move", json={"dir": direction}, headers=headers)
    return r.json()

answer = move("north")
print(answer["message"])
✅ Проехал
"moved": true, "x": 0, "y": 1
«Ровер на (0, 1): песок»
🧱 Упёрся
"moved": false, "blocked_by": "rock"
«Впереди скала — дальше не проехать»
💎 Находка
"found": "crystal" или "page"
Страница приходит целиком: номер, текст, буква

Ошибся в направлении ("up") — сервер ответит 400 и подскажет, какие слова можно.

8
Правила игры

Что важно знать

⏱️

Ровер не спешит

Одна клетка — четверть секунды. Ждёт сам сервер, sleep писать не нужно.

🧱

Стена — не беда

Скала, дверь или край: moved = False, ровер стоит на месте.

🏜️

Зыбучий песок

Авария: эвакуатор везёт ровер на базу, crashes +1. Но сканер песок видит!

🎒

Находки — твои

Кристаллы и страницы у каждого свои. Сосед ничего у тебя не заберёт, а ты — у него.

🚚

Эвакуатор

POST /rover/home — на базу в любой момент. Находки остаются.

☁️

Туман общий

Куда заглянул сканер любого ровера — клетка открыта для всего класса.

Пример прохождения · среднее

Ехать, пока едется

Сколько клеток до скалы — неизвестно. Значит, for не подходит, нужен while: едем, пока сервер отвечает moved: True.

crystals = 0
while True:
    answer = move("east")
    if not answer["moved"]:
        break                 # упёрлись
    if answer.get("found") == "crystal":
        crystals += 1

print("Стоп на", answer["x"], answer["y"])
print("Кристаллов:", crystals)

Пример: ровер проехал 5 клеток, подобрал 1 кристалл и упёрся в скалу. Сколько выйдет у тебя на востоке от базы?

Пример прохождения · среднее

Смотри, прежде чем ехать

def safe_move(direction):
    ahead = scan()["around"][direction]
    if ahead in ("trap", "rock", "edge", "door"):
        print("Впереди", ahead, "— стоп")
        return False
    move(direction)
    return True

while safe_move("north"):
    pass     # цикл в одну строку!
💥 Без проверки
Ровер въезжает в зыбучий песок → эвакуатор → снова на базе. Авария засчитана.
🛡️ С проверкой
Сканер видит trap впереди — ровер останавливается за клетку до беды.

14
Босс-уровень

Объехать всю планету

Программа, которая сама исследует каждую клетку. Идея — поиск в глубину:

1

Стою на клетке и смотрю сканером по сторонам.

2

Вижу новую безопасную клетку — заезжаю туда.

3

Исследую её точно так же — функция вызывает сама себя.

4

Возвращаюсь назад и смотрю следующую сторону.

visited = set()

def explore(x, y):
    visited.add((x, y))
    around = scan()["around"]
    for d, (dx, dy) in STEP.items():
        new = (x + dx, y + dy)
        if new in visited:
            continue
        if around[d] in STOP:
            continue
        move(d)
        explore(*new)   # рекурсия!
        move(BACK[d])   # назад

Обход идёт пару минут — включайте проектор и смотрите, как туман исчезает. Награда — ачивка 🛰️ Первопроходец.
